# DSH LEWIS ENCHANT · 附魔台｜开机动画

## 产品介绍

自定义你的开场，封面与声音。

「附魔台」是 DSH LEWIS ENCHANT 的统一品牌，「开机动画」是本插件的功能名称。为 DeepSeek Harness 带来完整开场、DeepSeek 标题封面，以及按任意键进入的游戏式启动体验。

## 产品功能

- **完整开场**：内置「启」「数字生命」「朋克」「半面」「鲸鱼娘」五段视频和「莱茵生命」动画，视频按原长度、原速播放，铺满当前 Harness 窗口，保持窗口大小、位置和最大化状态。
- **任意键进入**：动画中按任意键或点击画面进入标题页，再操作一次进入 Harness；动画自然结束后也会停留在标题页。
- **三款标题封面**：远山、黑金、蓝雾，保留原有图片与文字。
- **自定义素材**：上传自己的视频作为开场，上传喜欢的图片作为结束封面。
- **播放偏好**：启动时播放、播放声音、随机开场，三个开关即可设置；开场视频始终铺满当前窗口。
- **启动检查更新**：每次重新打开 Harness 自动检查新版本，开场结束并进入应用后再提醒；可选择稍后或直接更新，无需先卸载。
- **雾光更新提醒**：半透明磨砂弹窗，使用统一的磨砂度与圆角。
- **可选快捷入口**：默认从设置进入，可自行开启头像上方的“开机动画”按钮；附魔台系列共享最多 17 个快捷入口。
- **本地保存**：个人视频、图片和播放偏好保存在本机，正常更新后保留。
- **恢复默认**：设置底部可一键恢复安装时的状态；二次确认后重置全部偏好并永久删除所有上传的视频和图片，保留内置动画与封面。
- **作者信息**：设置底部可查看作者提供的微信收款码图片。
